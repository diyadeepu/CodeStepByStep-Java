# Problem: FearTheTree

Write Java statements that print the following console output:

```sql
\\\\\\\\\\\\\\\\\\\\
|| FEAR THE TREE! ||
////////////////////
```

### Solution

```sql
System.out.println("\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\");
System.out.println("|| FEAR THE TREE! ||");
System.out.println("////////////////////");
```
